# Overview
Deploys a small Go service that mints short-lived kubeadm bootstrap tokens
and serves a per-node `curl | bash` join script -- so adding a physical or
external machine (no BMC, no CAPI infrastructure provider available) to the
cluster is as simple as declaring it in `nodes:` below and running one
command on the target box.

Every request to `GET /bootstrap/{name}` requires `Authorization: Bearer
<fetchToken>` and a `name` that's actually declared in `nodes:` -- anything
else gets 401/404. The RBAC this chart creates is scoped to
`create`/`get`/`delete` on Secrets in `kube-system` only (the same
permission `kubeadm token create` itself needs), nothing broader.

Only `osFamily: ubuntu` is implemented today.
